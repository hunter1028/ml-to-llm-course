# 机器学习到大模型：技术演进与工业落地实战

一套从传统机器学习、经典深度学习到 Transformer、大模型对齐与工业落地的系统课程，共 40 课时。

## 课程内容

课程按照技术演进关系划分为六个模块：

1. **导论、数学与工程基础**：行业认知、学习方法、线性代数、概率统计、微积分与优化。
2. **传统机器学习与工业实战**：机器学习通用理论、线性模型、聚类、降维、树模型、Boosting 与决策优化。
3. **经典深度学习**：全连接网络、CNN、RNN、LSTM、GRU 及其适用场景。
4. **Transformer 与大模型原理**：自注意力、Encoder/Decoder、预训练和模型对齐。
5. **大模型微调与工业落地**：LoRA、工程优化和端到端综合项目。
6. **职业发展与技术复盘**：技术体系复盘、岗位方向、项目整理和后续学习规划。
