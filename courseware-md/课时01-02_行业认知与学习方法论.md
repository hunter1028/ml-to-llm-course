# 课时01-02：行业认知与学习方法论

## 1. 课程定位

建立 AI 学习全局地图，先看问题、数据、模型、评估、落地。

| 核心问题 | 本课回答 |
|---|---|
| AI 在做什么 | 从数据中学习规律，用规律预测新样本 |
| 为什么从机器学习走到大模型 | 数据类型、任务复杂度、模型能力不断升级 |

核心直觉：

> 模型不是背答案，而是从历史样本中学习规律，并迁移到新样本。

## 4. AI 建模最小闭环

AI 建模不是一上来选模型，而是先把业务问题翻译成数据问题。

| 步骤 | 问题 | 产物 | 例子 |
|---|---|---|---|
| 业务问题 | 要解决什么 | 任务定义 | 预测房价 |
| 数据收集 | 有哪些历史样本 | 数据表 | 面积、房间数、房龄、价格 |
| 特征设计 | 用什么信息预测 | $X$ | 面积、房间数、房龄 |
| 标签定义 | 要预测什么 | $y$ | 房价 |
| 模型训练 | 学到什么规律 | 参数 | $w,b$ |
| 模型预测 | 新样本输出什么 | $\hat{y}$ | 新房子的预测价格 |
| 效果评估 | 预测准不准 | 指标 | MSE、MAE、误差分布 |
| 业务落地 | 是否产生价值 | 决策 | 定价、推荐、审批 |

最小公式：

$$
\hat{y}=f(X)
$$

线性回归中：

$$
\hat{y}=Xw+b
$$

## 5. 房价预测案例

历史数据：

| 样本 | 面积 $m^2$ | 房间数 | 房龄 | 房价/万元 |
|---:|---:|---:|---:|---:|
| 1 | 60 | 2 | 18 | 185 |
| 2 | 75 | 3 | 12 | 248 |
| 3 | 90 | 3 | 8 | 312 |
| 4 | 105 | 4 | 15 | 340 |
| 5 | 120 | 4 | 6 | 420 |

预测问题：

| 新房子 | 面积 | 房间数 | 房龄 | 要预测 |
|---|---:|---:|---:|---|
| A | 100 | 3 | 10 | 房价 $\hat{y}$ |

人工判断和机器学习的区别：

| 方式 | 怎么做 | 优点 | 局限 |
|---|---|---|---|
| 人工经验 | 看面积、地段、房龄，大致估价 | 直观、快 | 难规模化，标准不稳定 |
| 规则系统 | 写死规则，例如每平米多少钱 | 可解释 | 规则复杂后难维护 |
| 机器学习 | 从历史数据自动拟合参数 | 可批量、可评估、可更新 | 依赖数据质量 |

## 6. AI 基础概念

| 概念 | 含义 | 房价案例 |
|---|---|---|
| 样本 | 一条历史记录 | 一套房子 |
| 特征 | 用来预测的信息 | 面积、房间数、房龄 |
| 标签 | 要预测的答案 | 房价 |
| 模型 | 从特征到标签的函数 | $\hat{y}=Xw+b$ |
| 参数 | 模型内部可学习的数 | $w,b$ |
| 训练 | 调整参数，让误差变小 | 找最合适的 $w,b$ |
| 预测 | 用训练好的模型算新样本 | 预测 100 平米房价 |
| 损失 | 衡量预测错多少 | MSE、MAE |
| 泛化（Generalization） | 对新样本也有效 | 不只记住历史房子 |

核心关系：

$$
\text{数据}(X,y) \rightarrow \text{训练} \rightarrow \text{模型}(f) \rightarrow \text{预测}(\hat{y})
$$

## 7. 线性回归直觉

线性回归假设：标签可以由多个特征加权相加得到。

单个样本：

$$
x=\begin{bmatrix}100 & 3 & 10\end{bmatrix}
$$

权重：

$$
w=\begin{bmatrix}w_1\\w_2\\w_3\end{bmatrix}
$$

预测：

$$
\hat{y}=100w_1+3w_2+10w_3+b
$$

每个参数的直觉：

| 参数 | 含义 | 可能影响 |
|---|---|---|
| $w_1$ | 面积权重 | 面积越大，价格通常越高 |
| $w_2$ | 房间数权重 | 房间数增加可能提高价格 |
| $w_3$ | 房龄权重 | 房龄越大，价格可能下降 |
| $b$ | 基础价格 | 不被特征解释的基础项 |

训练目标：

$$
\min_{w,b}\ L(w,b)
$$

常用损失：

$$
L=\frac{1}{m}\sum_{i=1}^{m}(y_i-\hat{y}_i)^2
$$

直觉：找到一组 $w,b$，让整体预测误差最小。

## 8. 训练和预测

| 阶段 | 输入 | 计算 | 输出 |
|---|---|---|---|
| 训练 | 历史 $X,y$ | 不断调整 $w,b$，降低损失 | 最优参数 |
| 预测 | 新样本 $X_{new}$ | 代入 $\hat{y}=X_{new}w+b$ | 预测结果 |

训练不是记忆表格，而是学习趋势。

| 记忆 | 泛化 |
|---|---|
| 只会回答见过的样本 | 能处理没见过的新样本 |
| 历史数据变多时难维护 | 参数可重新训练 |
| 对噪声敏感 | 能提取主趋势 |

好模型的标准：

| 维度 | 问题 |
|---|---|
| 训练误差 | 历史数据上是否拟合得好 |
| 测试误差 | 新数据上是否仍然准确 |
| 稳定性 | 数据轻微变化时结果是否稳定 |
| 可解释性 | 是否能说明特征为什么影响结果 |
| 业务价值 | 是否能辅助真实决策 |

## 9. 简单模型的边界

线性回归适合关系相对简单、趋势近似线性的任务。

| 问题 | 线性回归的困难 | 后续对应技术 |
|---|---|---|
| 特征很多 | 人工处理复杂 | 特征工程（Feature Engineering）、正则化（Regularization） |
| 关系非线性 | 一条直线不够 | 树模型、神经网络 |
| 图片/语音/文本 | 原始特征难设计 | CNN、RNN、Transformer |
| 业务分布变化 | 旧规律失效 | 监控、重训、漂移检测 |
| 异常值较多 | 参数容易被带偏 | MAE、Huber、鲁棒建模 |

结论：简单模型不是低级模型，关键看任务是否匹配。

## 10. AI 技术演进地图

| 阶段 | 核心能力 | 典型数据 | 代表模型 | 主要瓶颈 |
|---|---|---|---|---|
| 传统机器学习 | 表格建模、特征工程 | 结构化数据 | 线性模型、树模型、GBDT | 人工特征依赖强 |
| 深度学习 | 自动提取复杂特征 | 图像、语音、序列 | CNN、RNN、MLP | 数据和算力要求高 |
| Transformer | 长距离依赖建模 | 文本、多模态序列 | BERT、GPT、T5 | 训练成本高 |
| 大模型 | 通用语言理解与生成 | 海量文本、多模态 | GPT 类、LLaMA 类 | 落地成本、幻觉、评估 |

演进原因：

| 从哪里到哪里 | 主要驱动力 |
|---|---|
| 传统 ML → 深度学习 | 人工特征难以覆盖图片、语音、文本的复杂模式 |
| 深度学习 → Transformer | RNN 长序列效率低，CNN 全局建模能力有限 |
| Transformer → 大模型 | 规模扩大后出现更强的通用表达、迁移、生成能力 |

## 11. 传统机器学习仍然重要

传统机器学习仍是工业界刚需。

| 适合任务 | 常见场景 | 为什么适合 |
|---|---|---|
| 风控评分 | 信贷审批、反欺诈 | 表格数据多，可解释性强 |
| 用户流失预测 | 会员运营、订阅续费 | 样本结构清晰，目标明确 |
| 销量预测 | 零售、供应链 | 历史数据稳定，成本低 |
| 推荐排序特征 | 电商、内容推荐 | 可和深度模型组合 |
| 运营策略优化 | 优惠券、触达策略 | 部署简单，迭代快 |
| 异常检测 | 设备、交易、日志 | 小数据也能有效 |
| 客户分层 | CRM、营销 | 解释方便，业务易接受 |

核心原因：

| 原因 | 说明 |
|---|---|
| 表格数据最多 | 企业核心数据通常在数据库和业务系统里 |
| 训练成本低 | CPU 也能跑，迭代快 |
| 可解释性强 | 方便和业务、风控、合规沟通 |
| 上线简单 | 服务化成本低，监控容易 |
| 小数据可用 | 不必依赖海量数据和大算力 |

## 12. 深度学习和大模型的出现

| 技术 | 解决的问题 | 典型任务 | 代价 |
|---|---|---|---|
| 深度学习 | 人工特征太难设计 | 图像识别、语音识别、序列预测 | 数据、算力、调参成本更高 |
| Transformer | 长序列建模和并行训练 | 翻译、文本理解、生成 | 结构复杂，显存需求高 |
| 大模型 | 多任务通用能力和自然语言交互 | 问答、写作、代码、Agent、RAG | 成本、幻觉、安全、评估困难 |

三代技术不是替代关系，而是工具箱关系：

| 业务问题 | 更常用方案 |
|---|---|
| 表格风控、销量预测 | 传统机器学习 / GBDT |
| 图像检测、语音识别 | 深度学习 |
| 文档问答、知识助手、代码生成 | 大模型 + RAG / Agent |
| 复杂工业系统 | 传统模型 + 深度模型 + 大模型组合 |

## 13. 工业落地视角

训练指标和企业目标不同。

| 训练侧目标 | 企业侧目标 |
|---|---|
| 准确率更高 | 能否提升收入 |
| loss 更低 | 能否降低成本 |
| 模型更复杂 | 能否稳定运行 |
| 指标更漂亮 | 能否解释给业务方 |
| demo 能跑 | 能否接入真实流程 |
| 实验成功 | 出错后能否排查 |

工业模型最怕的问题：

| 问题 | 后果 |
|---|---|
| 训练数据和真实数据不一致 | 上线后效果下滑 |
| 离线指标好，线上指标差 | 无法产生业务价值 |
| 模型不可解释 | 业务方不敢用 |
| 推理太慢 | 影响用户体验 |
| 无监控 | 出问题发现太晚 |
| 无反馈闭环 | 模型无法持续变好 |

工业闭环：

$$
业务问题 \rightarrow 数据 \rightarrow 模型 \rightarrow 决策 \rightarrow 业务结果 \rightarrow 反馈迭代
$$

## 15. 学习方法

| 错误学法 | 问题 | 正确做法 |
|---|---|---|
| 只背算法名字 | 面试和项目都说不深 | 每个算法都问：解决什么问题 |
| 只看公式 | 不会落地 | 公式、代码、业务案例一起学 |
| 只调包 | 不懂参数和指标 | 至少知道输入、输出、损失、评估 |
| 追最新模型 | 基础不稳 | 先建立 ML → DL → LLM 主线 |
| 只做 demo | 项目价值弱 | 做成可解释、可复盘、可展示的项目 |

两个月路线：

| 周期 | 重点 | 产出 |
|---|---|---|
| 第 1-2 周 | 数学基础、Python、NumPy、Pandas | 数据处理小练习 |
| 第 3-4 周 | 传统 ML、特征工程、模型评估 | 表格预测项目 |
| 第 5-6 周 | 深度学习、CNN/RNN、Transformer 入门 | 图像或文本小项目 |
| 第 7-8 周 | 大模型应用、RAG、微调认知、项目包装 | 综合项目和简历表达 |

课程产出地图：

| 阶段 | 产出 |
|---|---|
| 数学与工程基础 | 环境、NumPy/Pandas、矩阵运算 |

## 16. 代码实操：线性回归最小示例

目标：用面积、房间数、房龄预测房价。

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, mean_absolute_error

# X: 面积、房间数、房龄
X = np.array([
    [60, 2, 18],
    [75, 3, 12],
    [90, 3, 8],
    [105, 4, 15],
    [120, 4, 6],
])

# y: 房价 / 万元
y = np.array([185, 248, 312, 340, 420])

model = LinearRegression()
model.fit(X, y)

print("w:", model.coef_)
print("b:", model.intercept_)

new_house = np.array([[100, 3, 10]])
pred = model.predict(new_house)
print("预测房价:", pred[0])

y_hat = model.predict(X)
print("MSE:", mean_squared_error(y, y_hat))
print("MAE:", mean_absolute_error(y, y_hat))
```

代码对应关系：

| 代码 | 数学含义 |
|---|---|
| `X` | 特征矩阵 |
| `y` | 标签向量 |
| `model.fit(X, y)` | 训练，求 $w,b$ |
| `model.coef_` | 权重 $w$ |
| `model.intercept_` | 偏置 $b$ |
| `model.predict()` | 预测 $\hat{y}$ |
| `mean_squared_error` | MSE 损失/评估 |

## 19. 知识延伸

理解 AI 项目的整体流程后，还需要用数学准确描述其中的数据、模型、误差和训练过程。

| 已有认识 | 对应的数学问题 |
|---|---|
| 数据表示成 $X,y$ | $X$ 的形状以及向量、矩阵的含义 |
| 模型输出 $\hat{y}$ | 矩阵乘法怎样完成批量预测 |
| 训练降低 loss | 导数、梯度和梯度下降（Gradient Descent）怎样工作 |
| 工业落地需要指标 | 概率统计怎样描述不确定性 |
